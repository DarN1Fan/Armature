# Product

## Register

product

## Users

React developers — from solo hackers to library authors — who want to add polished motion to their UI without leaving the codebase. They are technical, impatient with friction, and allergic to tools that feel heavier than the problem they solve. They are not motion designers; they think in components and props, not timelines and keyframes. Armature meets them where they are.

## Product Purpose

Armature is an open-source drop-in animation editor for React. Wrap any element with `AnimationBone`, reach for `AnimationEditor`, and get a full Blender-style timeline in your running app. No separate design tool, no export pipeline, no context switching. Success looks like: install, wrap, ship — and the animation works on the first real user's screen.

## Brand Personality

Precise · Technical · Focused. The tool that gets out of the way. Confident enough to make real decisions (dark UI, dense controls, Blender DNA) without performing approachability. It is a serious instrument for developers who take craft seriously.

## Anti-references

- **Figma** — too light, too much chrome. Armature is not a design tool with a developer mode; it is a developer tool with design power. No light surfaces, no floating inspector panels, no "clean white canvas" aesthetic.
- **Framer / Webflow marketing aesthetic** — glossy, gradient-heavy SaaS surfaces that prioritize selling over using. Armature is used, not sold.
- **Generic dev-tool gray** (CodeSandbox, StackBlitz clones) — forgettable gray IDE shells that feel like scaffolding. Armature has a point of view.

## Design Principles

1. **Zero friction, no ceremony** — The library should feel smaller than the problem it solves. Wrap one element. It works. Don't gate power behind setup wizards or required config.
2. **Signal over chrome** — Every UI element earns its pixel. No decorative scaffolding. The timeline, the playhead, the keyframe dot — each is doing work, not filling space.
3. **The tool disappears** — When the animation is built, Armature recedes. The animated UI is the product; Armature is the instrument that made it.
4. **Technical confidence** — Speak to developers as developers. Use precise vocabulary (frames, easing curves, pivot points). Don't soften the power with approachability theater.
5. **Blender DNA, React idioms** — Borrow Blender's spatial confidence and keyboard-driven density, then map it to React mental models (props, state, composition). Not a port; a translation.

## Accessibility & Inclusion

WCAG AA. Keyboard navigation throughout the editor. Since Armature is an animation tool, `prefers-reduced-motion` should be respected in any Armature-authored UI motion that ships to end users.
